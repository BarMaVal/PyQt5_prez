Установка и настройка

Подготовка рабочего окружения

📦 Установка PyQt5

Для установки PyQt5 используйте менеджер пакетов pip:

Команда установки
pip install PyQt5

️ Лицензии: PyQt5 vs PySide2

PyQt5 распространяется под лицензией GPL:

  • Для коммерческого закрытого проекта нужно либо открыть исходный код, либо купить коммерческую лицензию
  • Для учебных и открытых проектов — бесплатно

Альтернатива: библиотека PySide2 от компании Qt с лицензией LGPL (разрешает коммерческое использование без открытия кода).

Альтернатива: PySide2
# Установка PySide2 (лицензия LGPL)
pip install PySide2

# Разница только в импортах:
# PyQt5:
from PyQt5.QtWidgets import QApplication, QWidget

# PySide2:
from PySide2.QtWidgets import QApplication, QWidget

# API идентичен — меняется только название библиотеки!

✅ Проверка установки

После установки проверьте, что всё работает:

from PyQt5.QtWidgets import QApplication

app = QApplication([])

Структура PyQt5-приложения

Обязательные элементы минимальной программы

🔑 Обязательные элементы

Любое PyQt5-приложение содержит следующие обязательные элементы:

  1. from PyQt5.QtWidgets import ... — импорт нужных виджетов
  2. app = QApplication([]) — создание объекта приложения
  3. Создание окна (QWidget)
  4. window.show() — отображение окна
  5. app.exec_() — запуск цикла событий

Важно: В PyQt5 используется exec_(), а не exec(), потому что exec является зарезервированным словом в Python 2.

Python — минимальное приложение
from PyQt5.QtWidgets import QApplication, QWidget, QLabel

# 1. Создаём объект приложения
app = QApplication([])

# 2. Создаём главное окно
window = QWidget()
window.setWindowTitle("Моё первое приложение")
window.resize(400, 300)

# 3. Создаём виджет и показываем окно
label = QLabel("Привет, PyQt5!")
label.setParent(window)
window.show()

# 4. Запускаем цикл событий приложения
app.exec_()

📋 Порядок выполнения

1

Объектная модель PyQt

Всё в PyQt — это объекты

🧩 Объектно-ориентированный подход

В PyQt5 всё является объектами (виджетами). Каждый виджет имеет:

  • Свойства (properties) — характеристики объекта (текст, размер, цвет)
  • Методы (methods) — функции для работы с объектом (setText(), show())
  • Сигналы (signals) — события, которые объект может генерировать (клик, изменение текста)
  • Слоты (slots) — функции, которые выполняются при получении сигнала
📦

Виджеты

Все элементы интерфейса — объекты классов: QWidget, QPushButton, QLabel.

🔗

Сигналы и слоты

Механизм связи между объектами: сигнал → слот (функция-обработчик).

🌳

Иерархия

QWidget — базовый класс. Все виджеты наследуют от него.

⚙️

События

Действия пользователя (клики, нажатия клавиш) генерируют события.

Python — пример работы с объектами
from PyQt5.QtWidgets import QPushButton

# Создаём объект кнопки
button = QPushButton("Нажми меня")

# Свойства объекта
button.setText("Новый текст")
button.resize(200, 50)

# Сигналы и слоты
button.clicked.connect(on_button_click)

# Когда пользователь кликает:
# 1. Генерируется сигнал clicked
# 2. Вызывается слот on_button_click()

💡 Ключевая идея

PyQt5 построен на принципе "сигналы и слоты":

  • Сигнал — сообщение о том, что что-то произошло (клик, изменение текста)
  • Слот — функция, которая выполняется при получении сигнала
  • Связь — устанавливается через метод connect()

QWidget — базовое окно

Родительский класс для всех виджетов

🪟 Что такое QWidget?

QWidget — это базовый класс для всех виджетов в PyQt5. Он представляет собой прямоугольную область на экране.

Основные возможности:

  • Создание окна приложения
  • Установка заголовка, размера и позиции
  • Добавление других виджетов (кнопок, меток, полей ввода)
  • Управление внешним видом (цвет фона, границы)
Python — создание окна
from PyQt5.QtWidgets import QWidget

# Создаём окно
notes_win = QWidget()

# Устанавливаем заголовок окна
notes_win.setWindowTitle("Умные заметки")

# Устанавливаем размер (ширина, высота)
notes_win.resize(900, 600)

# Показываем окно
notes_win.show()

📐 Методы QWidget

  • setWindowTitle(title) — устанавливает текст заголовка окна
  • resize(width, height) — устанавливает размер окна
  • setGeometry(x, y, width, height) — устанавливает позицию и размер
  • show() — отображает окно на экране
  • hide() — скрывает окно
  • close() — закрывает окно
  • setStyleSheet(css) — применяет CSS-стили

QPushButton — кнопка

Создание интерактивных кнопок

Назначение QPushButton

QPushButton — это кнопка, которую пользователь может нажать. При нажатии генерируется сигнал clicked, который можно связать с функцией-обработчиком (слотом).

Это ключевая концепция PyQt! Механизм "сигналы и слоты" позволяет связывать действия пользователя с кодом программы.

Python — создание кнопки
from PyQt5.QtWidgets import QPushButton

# Создаём кнопку с текстом
button_note_create = QPushButton("Создать заметку")

# Методы кнопки
button_note_create.setText("Новый текст")
button_note_create.resize(200, 50)

# Сигналы и слоты — ключевая идея PyQt!
button_note_create.clicked.connect(on_create_click)

# Функция-обработчик (слот)
def on_create_click():
    print("Кнопка нажата!")

Интерактив: кнопка с изменением текста

Нажмите на кнопку, чтобы увидеть, как работает сигнал clicked и слот.

🔗 Концепция сигналов и слотов

Это основной механизм взаимодействия в PyQt5:

  1. Сигнал — событие, которое генерирует виджет (клик, изменение текста, фокус)
  2. Слот — функция, которая выполняется при получении сигнала
  3. Связь — устанавливается через signal.connect(slot)

QLineEdit — однострочное поле ввода

Ввод текста в одну строку + setEchoMode

✏️ Назначение QLineEdit

QLineEdit — виджет для ввода текста в одну строку. Используется для:

  • Ввода имени, email, пароля
  • Поиска и фильтрации
  • Ввода чисел и коротких текстов
Python — создание QLineEdit
from PyQt5.QtWidgets import QLineEdit

# Создаём поле ввода
field_tag = QLineEdit("")

# Устанавливаем текст-подсказку (placeholder)
field_tag.setPlaceholderText("Введите тег...")

# Методы QLineEdit
field_tag.setText("Новый текст")
current_text = field_tag.text()
field_tag.clear()
#запрещает пользователю редактировать текст внутри этого поля
field_tag.setReadOnly(True)

# Сигналы

# Сигнал textChanged отлавливает изменение текста и передает новый текст в функцию-обработчик.
field_tag.textChanged.connect(on_text_changed)
# когда пользователь нажмет клавишу Enter, находясь в поле field_tag, сработает функция on_enter
field_tag.returnPressed.connect(on_enter)

🔒 Метод setEchoMode() — режим отображения текста

Метод setEchoMode() управляет тем, как отображается введённый текст в поле. Это особенно полезно для полей пароля и конфиденциальных данных.

Доступные режимы:

  • QLineEdit.Normal — текст отображается как есть (режим по умолчанию)
  • QLineEdit.NoEcho — текст не отображается вообще (ничего не видно при вводе)
  • QLineEdit.Password — текст заменяется звёздочками (•••••)
  • QLineEdit.PasswordEchoOnEdit — текст показывается только во время редактирования, потом заменяется звёздочками
Python — примеры setEchoMode
from PyQt5.QtWidgets import QLineEdit

# Обычное поле — текст виден
name_field = QLineEdit()
name_field.setEchoMode(QLineEdit.Normal)
# Пользователь вводит "secret" → видно "secret"

# Поле пароля — текст заменяется звёздочками
password_field = QLineEdit()
password_field.setEchoMode(QLineEdit.Password)
# Пользователь вводит "secret" → видно "••••••"

# Ничего не отображается при вводе
secret_field = QLineEdit()
secret_field.setEchoMode(QLineEdit.NoEcho)
# Пользователь вводит "secret" → ничего не видно

# Показывается только во время ввода
pin_field = QLineEdit()
pin_field.setEchoMode(QLineEdit.PasswordEchoOnEdit)
# Пока печатаешь — видно, отпустил клавишу — звёздочки
🔒

Интерактив: режимы отображения

Переключайте режимы, чтобы увидеть, как setEchoMode() меняет отображение текста.

Все методы QLineEdit

  • text() — возвращает введённый текст
  • setText(text) — устанавливает текст
  • clear() — очищает поле
  • setPlaceholderText(text) — устанавливает текст-подсказку
  • setReadOnly(bool) — режим только для чтения
  • setEchoMode(mode) — режим отображения (Normal, Password, NoEcho, PasswordEchoOnEdit)

QTextEdit — многострочное поле + setHtml

Ввод большого текста и HTML-разметка

📝 Назначение QTextEdit

QTextEdit — виджет для ввода и отображения многострочного текста. В отличие от QLineEdit, поддерживает:

  • Несколько строк текста
  • Прокрутку (скроллинг)
  • Форматирование (жирный, курсив, цвет)
  • HTML-разметку
Python — создание QTextEdit
from PyQt5.QtWidgets import QTextEdit

# Создаём многострочное текстовое поле
field_text = QTextEdit()

# Методы QTextEdit
field_text.setPlainText("Текст заметки")
content = field_text.toPlainText()
field_text.append("Новая строка")
field_text.clear()

# Отличие от QLineEdit:
# QLineEdit — одна строка, метод text()
# QTextEdit — много строк, метод toPlainText()

🌐 Метод setHtml() — установка HTML-текста

Метод setHtml() позволяет установить текст с HTML-разметкой. QTextEdit поддерживает ограниченный набор HTML-тегов, что позволяет форматировать текст:

  • <b> — жирный текст
  • <i> — курсив
  • <u> — подчёркнутый
  • <font color="red"> — цвет текста
  • <br> — перенос строки
  • <h1>, <h2> — заголовки
  • <ul>, <li> — списки
Python — примеры setHtml
# Простой HTML с форматированием
field_text.setHtml("<b>Жирный текст</b> и <i>курсив</i>")

# HTML с цветом и заголовком
field_text.setHtml("""
    <h2 style="color: #4ec9b0;">Заголовок заметки</h2>
    <p>Обычный текст заметки.</p>
    <p style="color: red;">Важное предупреждение!</p>
    <ul>
        <li>Первый пункт</li>
        <li>Второй пункт</li>
    </ul>
""")

# HTML с изображением (локальный файл)
field_text.setHtml('<img src="image.png" width="200">')

# Получить HTML-содержимое обратно
html_content = field_text.toHtml()

# Разница между методами:
# setPlainText() — устанавливает обычный текст (без форматирования)
# setHtml() — устанавливает текст с HTML-разметкой
# toPlainText() — получает текст без HTML-тегов
# toHtml() — получает текст с HTML-тегами

QInputDialog — диалоговое окно

Получение данных от пользователя + getItem

💬 Назначение QInputDialog

QInputDialog — это модальное диалоговое окно для получения данных от пользователя. Используется для:

  • Ввода текста (название, имя)
  • Ввода чисел (возраст, количество)
  • Выбора из списка

Важно: Модальное окно блокирует основное окно, пока пользователь не закроет диалог.

Python — QInputDialog.getText()
from PyQt5.QtWidgets import QInputDialog

# Диалог ввода текста
note_name, ok = QInputDialog.getText(
    notes_win,
    "Добавить заметку",
    "Название заметки: "
)

if ok and note_name:
    print("Создана заметка:", note_name)
else:
    print("Отменено")

📋 Метод getItem() — выбор из списка

Метод QInputDialog.getItem() показывает диалог со списком вариантов, из которых пользователь может выбрать один. Это удобно, когда нужно предложить пользователю готовый набор опций.

Параметры:

  • parent — родительское окно
  • title — заголовок диалога
  • label — текст-подсказка
  • items — список вариантов (список строк)
  • current — индекс выбранного по умолчанию элемента (необязательно)
  • editable — можно ли редактировать список (необязательно)

Зачем нужны Layouts

Автоматическое расположение виджетов

📐 Проблема абсолютного позиционирования

Можно размещать виджеты по координатам (x, y):

Python — абсолютное позиционирование (плохо)
# Плохой подход — абсолютные координаты
button1.move(50, 100)
button2.move(200, 100)
button3.move(50, 150)

# Проблемы:
# 1. При изменении размера окна виджеты не двигаются
# 2. На разных экранах выглядит по-разному
# 3. Сложно поддерживать код

✅ Решение: Layouts

Layouts (менеджеры компоновки) автоматически располагают виджеты:

  • При изменении размера окна виджеты автоматически подстраиваются
  • Код становится чище и понятнее
  • Работает на всех экранах и разрешениях

QVBoxLayout

Располагает виджеты вертикально (сверху вниз).

QHBoxLayout

Располагает виджеты горизонтально (слева направо).

QGridLayout

Располагает виджеты в виде сетки (строки и столбцы).

📋

QFormLayout

Для форм с метками и полями ввода (пары ключ-значение).

Преимущества Layouts

  1. Адаптивность: виджеты автоматически подстраиваются под размер окна
  2. Простота: не нужно вычислять координаты
  3. Поддержка: легко добавлять и удалять виджеты
  4. Кроссплатформенность: одинаково выглядит на всех ОС

QGridLayout — сетка виджетов

Расположение в виде таблицы (строки и столбцы)

⊞ Назначение QGridLayout

QGridLayout располагает виджеты в виде сетки — как таблица со строками и столбцами. Каждый виджет размещается в определённой ячейке по координатам (строка, столбец).

Когда использовать:

  • Калькуляторы (кнопки в виде сетки)
  • Формы с несколькими полями ввода
  • Галереи изображений
  • Любой интерфейс, где нужна табличная структура
Python — QGridLayout
from PyQt5.QtWidgets import QGridLayout, QPushButton, QLabel

# Создаём сетку
grid = QGridLayout()

# Добавляем виджеты по координатам (строка, столбец)
# Метод: addWidget(widget, row, column)
grid.addWidget(QLabel("Имя:"), 0, 0)        # строка 0, столбец 0
grid.addWidget(name_input, 0, 1)            # строка 0, столбец 1
grid.addWidget(QLabel("Email:"), 1, 0)      # строка 1, столбец 0
grid.addWidget(email_input, 1, 1)           # строка 1, столбец 1

# Виджет может занимать несколько ячеек
# addWidget(widget, row, column, rowSpan, columnSpan)
grid.addWidget(big_button, 2, 0, 1, 2)     # занимает 1 строку и 2 столбца

window.setLayout(grid)

📐 Параметры addWidget()

Базовый синтаксис: addWidget(widget, row, column)

  • widget — виджет для добавления
  • row — номер строки (начинается с 0)
  • column — номер столбца (начинается с 0)

Расширенный синтаксис: addWidget(widget, row, column, rowSpan, columnSpan)

  • rowSpan — сколько строк занимает виджет
  • columnSpan — сколько столбцов занимает виджет
Python — пример: калькулятор
from PyQt5.QtWidgets import QGridLayout, QPushButton

grid = QGridLayout()

# Кнопки калькулятора в виде сетки 4x4
buttons = [
    ["7", "8", "9", "/"],
    ["4", "5", "6", "*"],
    ["1", "2", "3", "-"],
    ["0", ".", "=", "+"]
]

for row in range(4):
    for col in range(4):
        btn = QPushButton(buttons[row][col])
        grid.addWidget(btn, row, col)

window.setLayout(grid)

📋 Основные методы QGridLayout

  • addWidget(widget, row, column) — добавляет виджет в ячейку
  • addWidget(widget, row, column, rowSpan, columnSpan) — виджет на несколько ячеек
  • setSpacing(pixels) — отступы между ячейками
  • setColumnStretch(column, stretch) — коэффициент растяжения столбца
  • setRowStretch(row, stretch) — коэффициент растяжения строки

QFormLayout — формы с метками

QFormLayout — это специальный layout для создания форм. Он автоматически располагает виджеты в виде пар "метка — поле ввода":

Когда использовать:

  • Формы регистрации и входа
  • Настройки приложения
  • Анкеты и опросы
  • Любой интерфейс с парами "вопрос — ответ"

from PyQt5.QtWidgets import QFormLayout, QLineEdit, QPushButton

Вложенные Layouts и параметр stretch

Создание сложных интерфейсов с пропорциями

Вложение Layouts

Layouts можно вкладывать друг в друга для создания сложных интерфейсов. В приложении "Умные заметки" используется такая структура:

  • Главный layout (горизонтальный): layout_notes
  • Левая колонка (вертикальный): col_1 — текстовое поле
  • Правая колонка (вертикальный): col_2 — список заметок, теги, кнопки
Python — вложенные layouts из кода приложения

# Создаём главный горизонтальный layout
layout_notes = QHBoxLayout()

# Создаём левую колонку (вертикальный layout)
col_1 = QVBoxLayout()
col_1.addWidget(field_text)

# Создаём правую колонку (вертикальный layout)
col_2 = QVBoxLayout()
col_2.addWidget(list_notes_label)
col_2.addWidget(list_notes)
row_1 = QHBoxLayout()
row_1.addWidget(button_note_create)
row_1.addWidget(button_note_del)
col_2.addLayout(row_1)
row_2 = QHBoxLayout()
row_2.addWidget(button_note_save)
col_2.addLayout(row_2)
col_2.addWidget(list_tags_label)
col_2.addWidget(list_tags)
col_2.addWidget(field_tag)
row_3 = QHBoxLayout()
row_3.addWidget(button_tag_add)
row_3.addWidget(button_tag_del)
col_2.addLayout(row_3)
row_4 = QHBoxLayout()
row_4.addWidget(button_tag_search)
col_2.addLayout(row_4)

# Вкладываем колонки в главный layout
# stretch=2 и stretch=1 — пропорции 2:1
layout_notes.addLayout(col_1, stretch=2)
layout_notes.addLayout(col_2, stretch=1)

# Устанавливаем главный layout для окна
notes_win.setLayout(layout_notes)

📐 Параметр stretch — пропорции

Параметр stretch определяет пропорции, в которых layout'ы делят доступное пространство:

  • stretch=2 и stretch=1 — первый layout занимает 2/3, второй 1/3
  • stretch=1 и stretch=1 — равные доли (50/50)
  • stretch=3 и stretch=1 — первый занимает 3/4, второй 1/4

Формула: доля = stretch_i / сумма_всех_stretch

Изображения и видео в PyQt5

QPixmap, QLabel и QMediaPlayer

🖼️ Отображение изображений

Для работы с изображениями в PyQt5 используются классы QPixmap и QLabel:

  • QPixmap — хранит изображение в памяти
  • QLabel — отображает изображение на экране через метод setPixmap()
Python — отображение изображения
from PyQt5.QtWidgets import QLabel
from PyQt5.QtGui import QPixmap

# Создаём метку для изображения
image_label = QLabel()

# Загружаем изображение из файла
pixmap = QPixmap("photo.jpg")

# Проверяем, что изображение загрузилось
if not pixmap.isNull():
    # Масштабируем изображение под размер метки
    scaled_pixmap = pixmap.scaled(
        400, 300,                    # ширина и высота
        Qt.KeepAspectRatio,         # сохраняем пропорции
        Qt.SmoothTransformation     # плавное масштабирование
    )
    image_label.setPixmap(scaled_pixmap)
else:
    image_label.setText("Не удалось загрузить изображение")

  • QVideoWidget — виджет для отображения видео

def add_note():
    # 1. Открываем диалоговое окно для ввода названия
    note_name, ok = QInputDialog.getText(
        notes_win,
        "Добавить заметку",
        "Название заметки: "
    )
    
    # 2. Проверяем, нажал ли пользователь OK и ввёл ли текст
    if ok and note_name != "":
        # 3. Добавляем заметку в словарь (хранилище данных)

        print(notes)

Как решать распространённые проблемы

🐛 Типичные ошибки новичков

Ошибка 1: забыли app.exec_()
# ❌ Неправильно — окно появится и сразу закроется
notes_win.show()

# ✅ Правильно — запускаем цикл событий
notes_win.show()
app.exec_()

# ❌ Неправильно — нет объекта приложения
window = QWidget()
window.show()

# ✅ Правильно — сначала создаём app
app = QApplication([])
window = QWidget()
window.show()
app.exec_()
Ошибка 3: exec() вместо exec_()
# ❌ В PyQt5 это ошибка
app.exec()

# ✅ Правильно для PyQt5
app.exec_()
